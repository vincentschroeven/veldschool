# Veldschool Bois Laiterie

Initiatie natuurbeheer in korte modules, afgestemd op het perceel in Profondeville.
Installeerbare web-app (PWA) die offline werkt.

- Module 1: Inleiding natuurbeheer
- Module P: Paddenstoelen als getuigen (op basis van de Burnot Boswijzer)

Nieuwe module toegevoegd? Verhoog `VERSION` in `sw.js`, dan halen de telefoons de nieuwe versie op.
